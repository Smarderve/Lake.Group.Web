## Recurring rules (spec §61)

- Reuse the design system before building anything new.
- Loading / empty / error / success states on every API-backed screen.
- Frontend permissions are UX only — backend stays the security boundary.
- No hardcoded numbers, no invented endpoints, no secrets in the bundle.
